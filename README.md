# BotProverka

Telegram-бот для проверки других ботов с админ-панелью, тикетами и заявками.

## Функционал

- 📝 Подача заявлений на проверку ботов
- 🎫 Тикеты на пересмотр оценки
- 👨‍💼 Связь с админом через двусторонний мост
- 👤 Профили пользователей с привязкой ботов
- 📊 Статистика и админ-панель
- 📢 Рассылка сообщений
- 🛡 Антиспам
- 🔧 Редактор приветствия

## Запуск локально

1. Клонировать репозиторий
2. Установить зависимости: `pip install -r requirements.txt`
3. Настроить `config.py` (токен и ID админа)
4. Запустить: `python bot.py`

Или через `start.bat` (Windows).

## Переменные окружения

- `BOT_TOKEN` — токен бота от @BotFather
- `ADMIN_ID` — Telegram ID администратора
- `TGK_LINK` — ссылка на телеграм-канал
